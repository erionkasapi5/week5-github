\# Week 5 – GitHub Answers



\*\*1. What is the difference between git commit and git push?\*\*



Git commit saves changes locally in the repository. Git push uploads those commits to the remote repository on GitHub so they are available online.



\*\*2. What does origin mean in Git?\*\*



Origin is the default name Git gives to the remote repository from which the project was cloned. It allows us to refer to the GitHub repository without writing its full address every time.



\*\*3. How many complete copies of your project history exist now, and where are they?\*\*



There are two complete copies of my project history. One is stored locally on my computer, and the other is stored online on GitHub. Both contain the commits and project history that have been pushed.
