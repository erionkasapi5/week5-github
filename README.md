\# Week 5 GitHub Project



This repository contains my programming exercises and GitHub homework. It includes a simple C program that demonstrates basic output and user input. The project helps me practice Git, GitHub and Markdown.



\## Repository Files



\- `README.md` – Project description and instructions.

\- `hello.c` – C program that asks for the user's name.

\- `about.txt` – Information about the project.

\- `answers.md` – Answers to Git and GitHub questions.

\- `.gitignore` – Files that Git should ignore.

\- `LICENSE` – License for the project.



\## How to Run



Compile the C program using GCC:



```cmd

gcc hello.c -o hello.exe

```



Run the program:



```cmd

hello.exe

```
